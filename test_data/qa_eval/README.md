## 三、起草纪律（GT 反向污染防护）

1. 先读材料原文段落，独立写标准答案与期望引用；不反向照抄 AI 输出。
2. 每条 expected_citations 带完整来源身份（document_id + version_id + P 编号 + D 编号）；P→D 经 paragraph_map 换算（评测器内做防御性再换算）。
3. evidence_sufficiency 三态：answerable / insufficient / conflicting（弱冲突题在 notes 标注「弱冲突」）。
4. 期望答案要点（expected_answer_points）写「材料里的事实」，不写「希望 AI 说的话」。

## 四、LOCKED 使用纪律（四审 §9.2 落实版）

1. 每轮评测 LOCKED 只出汇总指标；逐题明细写 `qa_runs/<ts>/locked_detail/`，基线阶段不读取。
2. 首轮人工复核从 DEV 选题（已完成，见 qa_eval_20261022_203923_dev_90d7/review_10q.md）。
3. 任何需要查看 LOCKED 逐题结果定位错误的时刻，即将其转为**固定回归集**身份，此后不再作盲测证据。
4. LOCKED 未打开前，每轮迭代可跑汇总对比（不消耗盲测性）。
