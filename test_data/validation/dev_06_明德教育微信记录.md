# DEV-06 明德教育集团 · 校长与教务微信记录

> 材料形态：企微聊天记录｜行业：教育培训｜虚构数据｜⚠ 本案例为「真 deadline + 信号陷阱复测」设计
> 状态：**草稿（v0.1）**——未经曦复核锁定，禁止用于评测跑分

## 背景

明德教育是一家区域性课外培训机构，5 个校区，主营 K12 素质类课程。本次为校方校长（陈校长）与教务主管（李主管）在企微上向数析云咨询的聊天记录导出。

## 原始材料

P1 【陈校长】家长一直在反映，孩子上课情况我们都是事后才知道，家长问起来我们前台都答不上来。

P2 【陈校长】上周有个家长，孩子连着三周没来上课我们都没发现，人家直接要退费了。流失一个学员损失三千多，太亏了。

P3 【陈校长】我想要系统能自动发现连续两次没来上课的孩子，马上提醒校区顾问去跟进，别等人来退费才知道。

P4 【陈校长】这个事挺急的，暑期班六月一号开始招生，六月底前必须用上，招生季就是续费高峰，错过要再等半年。

P5 【李主管】还要能看到每个校区的续班率对比，现在都是教务月底手工拉表格，五个校区算下来要两天。

P6 【李主管】家长那边最好有个小程序能查孩子的课时余额和作业，家长问得最多的就是这个。

P7 【陈校长】小程序这事家长提了不止一次了，上次家长会好几个家长当场就问了。

P8 【李主管】我们用的是自研的学员管理系统，数据都在里面，当时外包开发留了接口文档。

P9 【陈校长】预算这块说实话不多，今年就批了三万，超了得重新打报告，流程要三个月。

P10 【陈校长】提醒最好走企业微信，顾问都用企微跟家长联系的。

P11 【李主管】对面那家机构做了个家长小程序，我们家长问了好几次为什么我们没有。

P12 【陈校长】小程序那个不着急，主要是先把缺课提醒和续班率的事弄好，别再流失孩子比什么都强。
