# 用户使用手册

> 面向系统的实际使用者。只讲操作，不讲原理。
> 在线地址：https://needs-analysis-workbench.app.workbuddy.host
> 演示账号：`admin@demo.cn`（管理员）、`pm@demo.cn`（产品经理）、`sales@demo.cn`（销售）、`presale@demo.cn`（售前），密码均为 `demo12345`

---

## 0. 开始前的三件事

1. **登录**：打开地址，用账号登录。没有账号 → 注册页自助注册（演示环境默认产品经理角色）。
2. **配模型 Key**（要跑真实分析的人必做）：右上角「模型设置」→ 粘贴你自己的 DeepSeek API Key → 保存。配好后，分析消耗你自己的额度，可在同一弹层查看用量。
3. **不配 Key 也能用**：清洗预览、报告查看、角色功能全部可用；只有「真实分析/真实问答」需要 Key（离线模式返回演示数据）。

**费用规则一句话**：清洗免费；完整分析一次约 0.3 元，从你的 Key 扣。

## 1. 产品经理：从一段材料到一条确认需求

### 1.1 新建分析

1. 侧栏「新建分析」。
2. 选场景（售前需求分析 / 学员服务诊断）。
3. 粘贴原始材料：每段一行，段前标 `P1`、`P2`……（不标也能清洗，但引用回链会缺失）。也可上传 .md/.txt 文件。
4. 点「清洗预览」（免费）。检查：段落编号是否正确、PII 是否已脱敏（手机号等会打码）。
5. 确认无误 → 点「运行完整分析」。等 1~2 分钟，完成后自动跳转报告。

### 1.2 读报告

报告有四个页签：

| 页签 | 内容 |
|---|---|
| 需求分析 | 显性需求（带原文引用）、潜在需求（推断，带置信度）、优先级 Top 6 |
| 能力匹配 | 产品能力 vs 需求的裁定：匹配 / 部分匹配 / 待确认 / 不支持 |
| 待确认追问 | 信息缺口 + 判断影响 + 建议追问话术 |
| 修正记录 | 所有确认、回复、意见的留痕（追加式，不覆盖历史） |

### 1.3 确认需求（核心动作）

1. 需求分析页签，目标需求行点「确认」。
2. 可填修改原因（建议填，留痕需要）。
3. 点「确认入库」→ 该需求状态变「已确认」，修正记录自动追加一条。

**原则：AI 结果是草稿，不确认不进需求池。**

### 1.4 导出

报告右上角「导出 Word」→ 下载 .docx（脱敏文本，可外发）。

### 1.5 材料问答

侧栏「材料问答」→ 选项目 → 提问。回答只依据该项目材料，附 D 编号引用。未配 Key 时用离线演示模式。

---

## 2. 销售：追问闭环

1. 侧栏「我的追问」：跨项目汇总所有待确认问题，决定性缺口排最前。
2. 每条追问有三块：缺口是什么、为什么影响判断、建议追问话术——照着问客户即可。
3. 客户回复后：点「录入回复」→ 粘贴客户原话 → 提交。状态变「已回复」，产品经理同步可见。
4. 你看到的报告只有追问视图；完整需求分析由产品经理把关。

---

## 3. 售前：能力匹配复核

1. 侧栏「能力匹配」：跨项目汇总所有非「匹配」结论，可按 部分匹配 / 待确认 / 不支持 筛选。
2. 对每条结论点「补充意见」：写能力边界、实现条件或方案建议（如「两层下钻需定制，POC 可演示一层」）。意见全员可见并留痕。
3. 「材料问答」可基于项目材料核对细节。

## 4. 管理员：成员与项目授权

### 4.1 邀请成员

管理控制台 →「邀请成员」→ 填姓名 / 邮箱 / 初始密码 / 角色 → 添加。成员用该邮箱和初始密码登录。

### 4.2 调整角色

成员列表的角色下拉直接改。角色职责：

| 角色 | 能做什么 |
|---|---|
| 管理员 | 成员、角色、项目授权 |
| 产品经理 | 全部业务功能 + 需求确认 |
| 销售 | 上传材料、追问闭环、问答 |
| 售前 | 能力复核、意见留痕、问答 |

### 4.3 项目访问控制

管理控制台底部「项目访问控制」：每个项目一个「受限访问」开关。

- 默认全员可见。
- 开启受限后：仅管理员、产品经理和被授权成员可见（其他人的列表里直接消失，直连链接也是 404）。
- 受限后按需勾选可见成员。

### 4.4 质量评测看板

侧栏「质量评测」：六指标四数据集的评测结果，了解系统当前的分析质量水位。

## 5. 常见问题

| 问题 | 处理 |
|---|---|
| 点「运行完整分析」报错「演示模式未配置 Key」 | 右上角「模型设置」配你自己的 DeepSeek Key |
| 列表里看不到某个项目 | 该项目被设为受限访问，找管理员授权 |
| 忘记密码 | 找管理员在成员页重置（演示环境） |
| 清洗预览和完整分析的区别 | 清洗纯代码不花钱、可反复调；完整分析调用模型，消耗 Key |
| 分析结果可以直接用吗 | 不可以。全部是草稿态，产品经理确认后才进需求池 |
| 回复客户问题想要依据 | 材料问答的每条回答带段落编号，可回链原文核对 |
