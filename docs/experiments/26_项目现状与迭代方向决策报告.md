P1 完成后若 ⑤ 仍想治，需要你先裁定期望：是接受指标现状，还是投入「新盲测集 + F7 矛盾规则」的组合轮次——那是下一个决策点，不在本轮。

## 附录：两轮失败实验归因摘要（面试叙事素材）

- **R1（Prompt v1.8，档位校准锚点）**：⑤ MAIN +0.116 但目标集零改善、4 处新偏（含 hold_03 高档被压）。教训：单次运行噪声与锚点效应量同级，双轮验收成为后续纪律。
- **R2-a（Prompt v1.9，归因直接性）**：主目标 final_01 EN2 两轮均未回档，3 处可重复新偏。根因：模型把「需求目标即止损」等同直接因果，判定键本身由模型裁量，条款咬不住。
- **共同结论**：⑤ 的分歧是语义层因果观问题，不是措辞问题——诚实止损、留档挂账，比继续烧 token 姿态更专业。
