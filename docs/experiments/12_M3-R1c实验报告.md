## 3. 核对结果

### 3.1 副作用是否消除（本轮主目标）✅ 达成

case_04 ⑥从 0.5 恢复 **1.0**。直接证据是大屏需求 EN8 的判定与理由：

- R1b：大屏合并进"3月底上线"条目判部分匹配；
- R1c：大屏独立成条判**匹配**，理由"C2 实时看板明确支持大屏投放，与 D011 大屏展示需求对应"——纯能力覆盖依据，**零优先级标签污染**。
- 附带收益：提取粒度恢复细粒度（10 条），R1b 的合并化消失；钻取/超预算提醒恢复两条、均判匹配。

### 3.2 case_05 维度分离是否保留 ✅ 完美保持

EN1（大屏挂指挥中心）四维分 **2/4/2/5 → 2.95（中），三轮 v1.1/v1.2 完全一致**。大屏族四条 impact 全部 1~2、signal 独立，反例锚点在靶案例上正常工作。

### 3.3 case_04 ⑤新回退（0.75→0.5）：归因清楚，不是修复失败

直接原因：语义配对 GT-EN4（对外大屏）↔ AI-EN8，GT=高（3.50 边界）vs AI=中（2.8）。拆开看：

| 事实 | 说明 |
|---|---|
| GT 口径 | case_04 大屏 impact=4（经销商大会商业影响）+ urgency=5（P9 硬期限）→ 3.50 高（边界）。GT 文档自注："强边界案例，预期评分人分歧最大，分歧本身就是要收集的数据" |
| AI 打分 | impact=2，理由"对外展示属对外形象展示，与核心痛点无直接关联，属锦上添花" |
| R1b 的"一致"是假象 | R1b 大屏与"3月底上线"合并成条，urg=5 搭车抬分到 4.2 高——合并巧合，非真实判定一致 |
| 反例锚点泛化风险 | AI 的"锦上添花"话术与 case_05 反例锚点表述一致——"对外展示=锦上添花"的心智从 case_05 带到了 case_04，未识别 case_04 大屏服务的是经销商大会这一商业事件（GT 潜在需求 IN3 明示伙伴信心压力） |

结论：**⑤回退是粒度恢复后暴露的真实分歧 + 反例锚点对"大屏"名词的跨案例过拟合**，不是作用域修复引入的回归。修复本身（3.1）与维度分离保持（3.2）均达成。

## 4. 分支判定与状态

对照建议文档 6.3 四分支：非 A（case_04 ⑤出新回退）、非 B（能力匹配已无污染证据）、非 C（粒度是恢复而非漂移）、非 D（维度分离未退化）。**实际判定：作用域修复达成，同时新暴露"反例锚点跨案例过拟合"问题。**

- Prompt v1.2 **保留**（副作用消除 + 靶案例效果稳定）；
- ⑥未完全回到 0.633 的差额来自 case_05 ⑥=0.333（R1b 同值，波动区间内）；
- 新增人工 Badcase 记录：case_04 BC-08 变体（反例锚点跨案例泛化，大屏 impact 2 vs GT 4）。

## 6. 本轮沉淀（面试叙事素材）

- 副作用修复的验收方式：不看平均分回升，看**病灶案例的判定理由是否换了依据**（从优先级标签 → 能力覆盖）——理由链证据比指标数字硬。
- 负结果的价值延续：R1b 的"一致"经细看是合并巧合，粒度恢复反而暴露真分歧——**指标对齐不等于判断对齐，评测要能区分这两种"一致"**。
