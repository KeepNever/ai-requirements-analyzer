# AI 输出摘录 · case_04_经销采购决策会

> 仅供独立评分用：只含事实层（需求条目/引用/追问），不含 AI 推理理由。

## 一、显性需求条目（指标③评分对象）

- **EN1** 需要销售实时看板，能看到当天回款、当天订单数据，供下午三点开会前查看当天早上的数据｜引用：P2
- **EN2** 需要费用报表支持按区域、按品类逐层钻取｜引用：P4
- **EN3** 费用超预算需要提醒，改变目前事后才知道超预算的状况｜引用：P4
- **EN4** 运营也需要提醒功能，库存周转天数超标时提醒采购，替代目前靠人盯的方式｜引用：P5
- **EN5** 财务费用表供全公司使用，除财务部外各区负责人也要查看自己那块的费用｜引用：P6
- **EN6** 销售看板的主要使用者是运营和陈总，最多再加供应链的人｜引用：P7
- **EN7** 3 月底必须上线｜引用：P9
- **EN8** 二季度全国经销商大会需要对外展示经营数据，大屏挂在前台供来访经销商观看｜引用：P9, P11
- **EN9** 数据安全要求很高，客户是医院，信息绝对不能出问题｜引用：P12
- **EN10** 需要重点说明部署方式（因之前服务器在国外的 BI 被 IT 否决）｜引用：P13

## 二、追问清单（指标④评分对象）

1. 【缺口】客户现有 ERP/CRM/财务系统及省区数据源的品牌与接口类型未知｜【问题】贵司目前使用的 ERP/CRM/财务系统分别是什么品牌和版本？省区销售数据目前是从哪个系统导出的？是否支持标准数据库或 API 对接？
2. 【缺口】私有化/本地化部署的具体要求（部署在客户内网还是指定云、是否有等保或行业合规要求）｜【问题】贵司对部署方式的具体要求是什么？是必须部署在自有内网，还是可接受国内合规云？是否有等保或医疗行业合规要求？
3. 【缺口】费用预算数据（预算科目、预算维度、超预算判定规则）的来源与维护方式｜【问题】费用预算数据目前维护在哪里（系统还是 Excel）？预算按什么维度设定（区域/品类/月度）？超预算的判定规则是怎样的？
4. 【缺口】库存周转天数数据来源及采购提醒的推送对象与渠道｜【问题】库存周转天数数据来自哪个系统？超标提醒需要推送给采购的哪些人？通过什么渠道推送（邮件/企业微信/钉钉）？
5. 【缺口】经销商大会对外展示的具体指标范围与展示形式｜【问题】经销商大会对外展示希望呈现哪些经营指标？是否有指定的展示形式或大屏尺寸要求？
