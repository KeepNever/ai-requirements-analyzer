开始前的三件事

1. 登录

打开系统地址，使用账号登录。演示环境账号（密码均为 demo12345）：

账号角色
admin@demo.cn管理员
pm@demo.cn产品经理
sales@demo.cn销售
presale@demo.cn售前

没有账号：注册页自助注册。演示环境注册默认产品经理角色。

2. 配置模型 Key（要跑真实分析的人必做）

右上角「模型设置」→ 粘贴你自己的 DeepSeek API Key → 保存。看到「已保存生效」即配置成功。配置后，真实分析与问答消耗你自己的额度；同一弹层可随时查看用量统计与清除 Key。

3. 费用规则

清洗预览免费；完整分析一次约 0.3 元，从你配置的 Key 扣。不配置 Key 也可使用：清洗预览、报告查看、全部角色功能均可正常使用，仅「真实分析 / 真实问答」不可用（离线模式返回演示数据）。

产品经理：从一段材料到一条确认需求

新建分析

第一步：侧栏点「新建分析」。

第二步：选择场景（售前需求分析 / 学员服务诊断）。

第三步：粘贴原始材料。每段一行，段前标 P1、P2……（不标注也能清洗，但报告中的引用回链会缺失）。也可以上传 .md 或 .txt 文件。

第四步：点「清洗预览」（免费）。检查两点：段落编号是否正确、手机号等隐私信息是否已脱敏打码。

第五步：确认无误后点「运行完整分析」。等待 1~2 分钟，完成后自动跳转报告页。

读报告

报告共四个页签：

页签内容
需求分析显性需求（带原文引用）、潜在需求（推断，带置信度）、优先级 Top 6
能力匹配产品能力与需求的裁定结果：匹配 / 部分匹配 / 待确认 / 不支持
待确认追问信息缺口 + 判断影响 + 建议追问话术
修正记录全部确认、客户回复、售前意见的留痕（追加式，不覆盖历史）

确认需求（核心动作）

在需求分析页签，目标需求行点「确认」→ 可填写修改原因（建议填写，留痕需要）→ 点「确认入库」。该需求状态变为「已确认」，修正记录自动追加一条。

原则：AI 结果全部是草稿态，未经产品经理确认不进入需求池。

导出 Word

报告右上角点「导出 Word」下载 .docx 文件，内容为脱敏文本，可直接外发。

销售：追问闭环

第一步：侧栏点「我的追问」。跨项目汇总所有待确认问题，决定性缺口排在最前。

第二步：每条追问包含三块信息——缺口是什么、为什么影响判断、建议追问话术。见客户时照着问即可。

第三步：客户回复后，点「录入回复」→ 粘贴客户原话 → 提交。状态变为「已回复」，产品经理同步可见。

销售看到的报告只有追问视图，完整需求分析由产品经理把关。

售前：能力匹配复核

侧栏点「能力匹配」：跨项目汇总所有非「匹配」结论，可按部分匹配 / 待确认 / 不支持筛选。

对每条结论点「补充意见」，填写能力边界、实现条件或方案建议（例如：两层下钻需定制开发，POC 可演示一层）。意见全员可见并自动留痕。

「材料问答」可基于项目材料核对功能细节。

管理员：成员与项目授权

邀请成员

管理控制台 → 点「邀请成员」→ 填写姓名、邮箱、初始密码、角色 → 添加。成员用该邮箱和初始密码登录。

调整角色

成员列表的角色下拉直接修改。各角色职责见文末速查表。

项目访问控制

管理控制台底部「项目访问控制」区域：每个项目一个「受限访问」开关。

默认全员可见。开启受限后，该项目仅管理员、产品经理和被授权成员可见——其他人的项目列表里直接消失，直连链接也返回 404。开启后可按需勾选可见成员。

质量评测看板

侧栏「质量评测」：查看六指标四数据集的评测结果，了解系统当前的分析质量水位。
