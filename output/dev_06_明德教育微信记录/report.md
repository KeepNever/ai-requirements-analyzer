## F1 客户背景

- 客户为多校区教育培训机构，共五个校区（D005）。
- 机构使用自研的学员管理系统，数据均在其中，外包开发时留有接口文档（D008）。
- 顾问日常通过企业微信与家长联系（D010）。
- 机构设有前台、校区顾问、教务等岗位（D001、D003、D005）。
- 机构即将进入暑期班招生季，六月一日开始招生（D004）。

## F2 业务目标

- 减少学员流失，避免因未及时发现缺课导致退费损失（D002、D012）。
- 在暑期招生季（六月一日开始招生、六月底前上线）前用上系统，抓住续费高峰（D004）。
- 提升家长对学员上课情况的知情度与满意度（D001、D006、D007）。

## F7 能力匹配

| 对象 | 结论 | 依据 |
|---|---|---|
| EN1 自动发现连续两次缺课并提醒顾问 | 部分匹配 | C4 智能预警支持指标阈值预警并可推送企业微信，可覆盖'发现异常并提醒'；但'连续两次没来'属于行为序列规则，需确认是否在阈值预警能力范围内，且数据依赖 C5 数据集成对接自研系统。 |
| EN2 六月底前上线 | 待确认 | 能力清单未包含交付周期信息，无法依据现有能力清单判断能否在六月底前完成，需结合数据集成定制工作量评估。 |
| EN3 各校区续班率对比 | 匹配 | C1 自助报表支持拖拽式报表搭建与 30+ 图表类型，C2 实时看板支持核心指标展示，可覆盖多校区续班率对比的报表/看板需求。 |
| EN4 家长端小程序查课时余额和作业 | 不支持 | 能力清单中 C6 移动端仅支持 iOS/Android 查看报表与预警，不支持移动端编辑报表，且无面向家长的外部小程序能力，现有能力无法覆盖家长端小程序。 |
| EN5 提醒走企业微信 | 匹配 | C4 智能预警明确支持邮件/企业微信/钉钉推送，与企业微信提醒需求直接对应。 |
| 对接自研学员管理系统数据（IN1） | 待确认 | C5 数据集成提供 50+ 标准连接器，私有协议需定制开发；自研系统是否属于标准连接器覆盖范围、接口文档是否可用尚不明确，需确认后判定。 |
