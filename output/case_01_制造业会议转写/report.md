## F1 客户背景

- 华宇为制造型企业，设有生产、质量、IT 等部门，王总为生产副总，李工为 IT 主管，质量部刘经理亦有参与相关诉求。
- 数据分散：主要数据在 ERP（金蝶 K3，已使用六年，版本较老），设备加工数据一部分在 MES，一部分仍在老系统，数据较杂。
- 当前质量报告为每周一次，良品率异常发现滞后，曾因发现晚导致整批返工，工时损失一万多元。
- 现有预警方式为文员每天早上导出 Excel 发工作群，人力投入大且不及时。
- 全厂办公沟通依托企业微信。
- 今年信息化专项预算剩余约二十万元。
- 计划三季度完成产线改造，新产线投产后需立即使用相关系统。

## F2 业务目标

- 提升良品率管控能力，避免因发现滞后造成整批返工损失（依据 D002）。
- 实现车间质量与设备数据的实时可视化，当天即可看到良品率、停机时长等指标（依据 D003）。
- 打通 ERP 与设备数据，为看板提供数据基础（依据 D005）。
- 实现良品率低于 95 时的即时预警通知（依据 D007）。
- 让多个车间主任等角色都能查看看板，而非仅管理层可见（依据 D010）。
- 在三季度产线改造完成后新产线投用时系统即可上线使用（依据 D012）。

## F7 能力匹配

| 对象 | 结论 | 依据 |
|---|---|---|
| EN1 实时看板（良品率、停机时长当天可见） | 匹配 | C2 实时看板支持核心指标实时刷新（延迟<1分钟）并支持大屏投放，覆盖'当天就能看到'的实时性要求。 |
| EN2 接入 ERP 与设备数据 | 部分匹配 | C5 数据集成提供 50+ 标准连接器（主流 ERP/CRM/数据库），金蝶 K3 属主流 ERP 有望覆盖；但设备侧 MES 及老系统数据格式老旧（D013），C5 明确私有协议需定制开发，设备侧接入存在缺口，故为部分匹配。 |
| EN3 良品率低于 95 即时预警通知 | 匹配 | C4 智能预警支持指标阈值预警，可满足良品率阈值触发通知的核心功能。 |
| EN4 预警走企业微信 | 匹配 | C4 智能预警明确支持邮件/企业微信/钉钉推送，企业微信推送在能力清单覆盖范围内。 |
| EN5 多个车间主任都能查看看板 | 匹配 | C2 实时看板支持大屏投放，C6 移动端支持 iOS/Android 查看报表与预警，可满足多角色查看看板需求。 |
| EN6 三季度上线时间要求 | 待确认 | 上线时间取决于数据集成（尤其设备侧定制开发）的工作量与周期，而设备接口可行性尚未确认（D013），缺少可判断交付周期的证据。 |
| IN1 批次追溯（问题批次对应产线、班次） | 待确认 | 能力清单中无批次追溯相关能力条目，C1 自助报表支持拖拽搭建但复杂计算字段需定制，能否通过报表+数据集成实现批次追溯缺少可行性证据，需确认。 |
