## F1 客户背景

- 客户为华宇，王总为生产副总，李工为IT主管，质量部刘经理也被提及
- 数据主要存放在ERP（金蝶K3，已使用六年，版本较老），设备加工数据一部分在MES，一部分在老系统中，数据来源较杂
- 当前质量报告每周才出一次，良品率预警靠文员每天早上导Excel发工作群
- 全厂办公使用企业微信
- 今年信息化专项预算还剩二十万左右
- 三季度产线改造完成，新产线将上线

## F2 业务目标

- 解决良品率问题，避免因发现问题晚导致整批返工（依据D002）
- 实现车间实时看板，当天即可查看良品率、停机时长等指标，不再等一周（依据D003）
- 实现良品率低于95时立即通知王总，不再依赖次日人工导表（依据D007）
- 看板需覆盖多个车间主任，而非仅王总办公室可见（依据D010）
- 赶在三季度产线改造完成、新产线投用时上线使用（依据D012）

## F7 能力匹配

| 对象 | 结论 | 依据 |
|---|---|---|
| EN1 | 匹配 | C2 实时看板支持核心指标实时刷新（延迟 < 1 分钟）并支持大屏投放，可满足'当天就能看到'的实时性要求。 |
| EN2 | 部分匹配 | C5 数据集成提供 50+ 标准连接器覆盖主流 ERP/数据库，ERP 侧（金蝶 K3）可能覆盖；但设备侧 MES 及老系统数据格式老、接口不确定（D013），私有协议需定制开发，故为部分匹配。 |
| EN3 | 匹配 | C4 智能预警支持指标阈值预警，可满足良品率低于 95 立即通知的需求。 |
| EN4 | 匹配 | C4 智能预警明确支持企业微信推送，与 D008 要求一致。 |
| EN5 | 匹配 | C2 实时看板支持大屏投放，C6 移动端支持 iOS/Android 查看报表，可满足多个车间主任查看的需求。 |
| EN6 | 待确认 | 批次追溯需按产线、班次维度关联查询，可能涉及复杂多表关联；C3 自然语言查询不支持复杂多表关联，C1 自助报表复杂计算字段需定制，现有能力能否覆盖批次追溯的关键功能证据不足，需确认数据模型后再判定。 |
| EN7 | 待确认 | 三季度上线的时间可行性取决于数据集成（尤其设备侧定制开发）的工作量，而设备接口可接入性尚未确认（D013），无法判定能否按期交付。 |
