## F1 客户背景

- 客户为物流/快递类企业，设有指挥中心、前台等物理场所（D001、D002）
- 客服部规模约30人（D009）
- TMS系统为自研，接口文档齐全，有技术人员可配合对接（D013）
- 月均投诉三百多单，异常件（破损、丢件、超时）目前依赖客户投诉后客服才知晓（D004）
- 投诉率是客服部KPI，老板高度关注（D006）
- 预算走今年客服降本专项，额度充足（D014）

## F2 业务目标

- 降低投诉率，实现环比下降，作为客服部年终总结的核心成绩（D012、D006）
- 变被动为主动：系统发现异常件后主动推送客服，客服主动联系客户，不再等客户投诉（D004、D005）
- 满足老板对指挥中心大屏的明确要求，用于合作伙伴参观时展示（D001、D002、D010）
- 让老板随时可见异常件管理情况（D008）

## F7 能力匹配

| 对象 | 结论 | 依据 |
|---|---|---|
| EN1 / 需要一块大屏，挂在指挥中心 | 匹配 | C2实时看板支持大屏投放，直接覆盖大屏展示需求；大屏硬件本身不在能力清单范围，但软件侧看板能力匹配 |
| EN2 / 大屏用于前台/参观场景展示数据 | 匹配 | C2实时看板支持大屏投放，可满足参观展示场景的数据呈现需求 |
| EN3 / 大屏展示内容由供应商给建议 | 匹配 | C1自助报表支持30+图表类型、C2实时看板支持核心指标展示，具备为客户建议展示内容并落地的能力 |
| EN4 / 系统发现异常件后主动推送给客服 | 匹配 | C4智能预警支持指标阈值预警及企业微信推送，可覆盖异常件主动推送需求；需从TMS集成异常件数据作为预警数据源，集成工作不构成降档理由 |
| EN5 / 从TMS异常件状态字段推送数据 | 匹配 | C5数据集成支持50+标准连接器，TMS为自研且接口文档齐全（D013），可通过标准连接器或定制对接实现；D013明确对接不难，实施工作写入reason但不降档 |
| EN6 / 大屏上展示异常件数据 | 匹配 | C2实时看板支持核心指标实时刷新与大屏投放，异常件数据可作为看板指标展示；数据源来自TMS集成 |
| EN7 / 客服部30人使用预警提醒，走企业微信推送到人 | 匹配 | C4智能预警明确支持企业微信推送，覆盖30人推送需求；C6移动端支持iOS/Android查看预警，可辅助客服接收 |
