# CASE-03 泰和保险 · 客户访谈笔记

> 材料形态：访谈笔记｜行业：保险｜虚构数据

## 背景

泰和保险某省分公司数据部经理冯经理接受数析云访谈，以下为访谈记录整理（访谈时长 45 分钟）。

## 原始材料

P1 受访人：冯经理，数据部经理，管理全省业务数据需求，下属团队 6 人。

P2 现状：业务部门要任何数据都要提需求到数据部，我们写 SQL 跑完再回。排队两三天是常态，领导临时要数就只能加班赶。

P3 冯经理原话：「我的愿望是业务自己能查数，简单的别再来找我。6 个人根本忙不过来，需求还在涨。」

P4 之前买过 A 厂商的 BI 产品，用了一年。业务部门反馈太复杂不会用，最后还是回来找数据部要数，第二年没有续约。

P5 对自然语言查数很感兴趣，现场要求演示：「直接打字问一句，系统就出数、出图」这种形态。

P6 但反复强调：出数必须准。保费、赔付这种数据错一分都是事故，宁可多等也不能给错数。

P7 数据全部在省公司机房，集团有数据安全规定：业务数据不允许出内网。

P8 访谈中主动问：「你们是 SaaS 吧？我们这种情况能不能私有化部署？这个是前提。」

P9 预算：分公司层面采购权限 50 万以内，超了要报集团。

P10 每天盯的核心指标：车险理赔进度、保费收缴率。

P11 冯经理：「如果真能让业务自己查数，我们部门就能腾出手做数据治理。这块欠账太多了，一直没人力做。」

P12 补充需求：每月给监管报送的报表是固定格式，现在手工做要两天，这个要是能自动生成就好了。

P13 访谈结束时冯经理表示：可以再安排两位业务部门代表参加下次沟通，让他们的诉求也直接讲一讲。
